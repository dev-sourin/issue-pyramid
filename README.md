# Issue Pyramid — 論点ピラミッド

スマホでイシューや仮説をピラミッド構造に分解し、頭の中でブレストするためのツールです。単一の HTML ファイルとして動作し、外部依存はありません。

## できること

- **アウトライン編集** — 各行の「…」メニューから子/兄弟の追加、インデント・アウトデント（親子の付け替え）、上下移動、削除ができます。ドラッグハンドルで兄弟内の並べ替えも可能です。
- **ピラミッド表示** — ツリーを自動レイアウトし、親子関係を線でつなぎます。ピンチズーム・パンに対応。
- **接続モード** — ピラミッド画面で2つの要素を順にタップするだけで、親子関係を組み替えられます。
- **MECEガイド** — 兄弟要素間に簡易的な MECE インジケーターを表示できます。
- **複数ピラミッドの管理・比較** — タブで複数のピラミッドを切り替え、比較ビューで2つ以上を並べて確認できます。
- データは端末のブラウザ（localStorage）に自動保存されます。

## 使い方

`index.html` をブラウザで開くだけで動作します。GitHub Pages でも公開しています。

## 技術

Vanilla HTML/CSS/JavaScript のみ。ビルド不要、外部ライブラリ不要です。
